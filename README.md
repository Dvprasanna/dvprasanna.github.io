# HTML Canvas & Utility Experiments

A personal collection of lightweight **HTML + JavaScript experiments**, focused on:

- 🎨 Canvas drawing & curves
- 📐 Grid / CAD-like tools
- 🧪 Geometry, math & visuals
- 🕹 Small games & UI tests
- 📱 Mobile-friendly (iPhone tested)

Most files are **single-file apps** (`.html`) and can be opened directly.
