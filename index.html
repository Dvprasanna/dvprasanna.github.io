Table Maker — Complete

Paste plain text here then select lines and click Make Table. Example: first second third 1) Select those lines and click Make Table → three rows. 2) Deselect. 3) Inside the first cell type: abcDEFghi Select "DEF" (only that part) and click Make Columns. Result: that row becomes two cells: DEF and abcghi (selected first, remaining next).
Workflow: select lines → Make Table. Then select part of a cell (or place caret) → Make Columns. Selected text becomes first column; remaining text (before+after selection) becomes the next column.
